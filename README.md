# Башмачок · Приёмка

Приложение приёмки товара на складе. Один HTML-файл, работает на телефоне
без интернета. Внутри вшита вся номенклатура Айтиды (~97 000 карточек) —
названия собираются конструктором строго по конвенциям базы и сверяются
с ней на лету.

## Как пользоваться на складе

1. Скачать «Башмачок Приёмка v8.html» на телефон и открыть в браузере.
2. Вкладка «Документ»: указать склад и номер груза.
3. Вкладка «Конструктор» — сверху вниз, как на листочке:
   сезон → категория → кому → артикул/бренд → размеры и количество → цвет.
   Название собирается само и сверяется с базой:
   - зелёная плашка — модель уже есть, пары встанут в её карточки;
   - жёлтая — новая, карточки создадутся при импорте;
   - оранжевая — артикул уже есть в базе: тап по названию подставит его точно.
4. Внизу «⬇ Excel для Айтиды» — файл прихода на 14 колонок.
5. Оператор на компе проставляет цены и контрагента и грузит файл в Айтиду
   через «Загрузка электронных накладных», шаблон «Приход».

Черновик (кнопка 💾) — это JSON: можно продолжить приёмку на другом
устройстве через 📂.

## Правила именования (зашиты в конструктор, проверены по базе 27.07.2026)

- сезон: `з.` зима, `л.` лето, без префикса — деми/всесезон
- `м.` — детская обувь (мальч./дев.), ставится автоматически
- пол и бренд слитно: `дев.онсун`, без бренда — `дев. 210-4`
- диапазон размеров `(26-31)` в названии только у детских
  (у взрослых в базе его нет: 0,2% против 99,7% у детских)
- цвет.материал.фасон через точку: `черн.кожа.лоф`
- размерная карточка = название + ` 37р` (без точки)

## Обновление базы

```
python update_base.py "вся база айтиды.xlsx"   # выгрузка «Список товаров» из Айтиды
python build.py                                 # пересобрать готовый HTML
```

## Файлы

| файл | что это |
|---|---|
| `Башмачок Приёмка v8.html` | готовое приложение (раздать складу) |
| `template.html` | шаблон интерфейса и логики |
| `base_data.js` | вшиваемая база `const BASE=[[имя,код,артикул],...]` |
| `xlsx.full.min.js` | SheetJS 0.18.5, вшивается для работы без интернета |
| `update_base.py` | выгрузка Айтиды → base_data.js |
| `build.py` | сборка готового HTML |
